# AgentWorks OS Logo Pack Draft

First-pass logo directions for AgentWorks OS.

## Context

AgentWorks OS needs to stand alone as a customer-facing product. The logo should not reference upstream substrate project names or look like an internal rebrand. It can keep portfolio continuity with SGRIDWORKS through disciplined color use, but the symbol should be AgentWorks-native.

Current positioning:

- Public wedge: AI compliance firewall for regulated small businesses
- Product reality: local-first memory, orchestration, audit, policy gates, approval queue, workflow automation, security scan
- Buyer signal: credible enough for regulated SMB operators, not playful AI tooling

## Palette

- Deep ink: `#173F49`
- Cyan accent: `#58C7D8`
- Evidence gold: `#D6A84E`
- Paper tint: `#F4FAFB`
- Muted slate: `#58737A`

## Directions

### 1. Gateway

Symbol files:

- `svg/agentworks-gateway-symbol.svg`
- `svg/agentworks-gateway-horizontal.svg`

Rationale: strongest fit for the compliance-firewall wedge. Reads as policy gate, controlled boundary, and local protection without becoming a generic cybersecurity shield.

### 2. Weave

Symbol files:

- `svg/agentworks-weave-symbol.svg`
- `svg/agentworks-weave-horizontal.svg`

Rationale: strongest fit for orchestration. The interlocked path suggests multiple agents coordinated through one operating layer. It is more platform-like and less compliance-forward.

### 3. Ledger

Symbol files:

- `svg/agentworks-ledger-symbol.svg`
- `svg/agentworks-ledger-horizontal.svg`

Rationale: strongest fit for audit trail and evidence reporting. The downside is ownability: checkmark-in-circle marks are common.

## Recommendation

Start from Direction 1, Gateway. It aligns with the buying reason, gives us credible app-icon geometry, and leaves room for the product to include memory and orchestration without making those internal mechanics the public identity.

The second iteration is in `gateway-iterations.html`. It keeps the Gateway concept but aligns it with the current SGRIDWORKS redesign:

- Fraunces wordmark
- JetBrains Mono OS label
- Cool paper background `#F4F6F4`
- Ink `#0F1618`
- Substation blue-green `#1C4855`
- Thin 32x32 SVG linework
- Engineering-grid preview surface

Second-pass candidates:

- `1A. Line Gate` is the recommended base mark.
- `1B. Spark Gate` is closest to the SGRIDWORKS family mark without copying it.
- `1C. Grid Gate` is the most operational/admin-UI friendly.
