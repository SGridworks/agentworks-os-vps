# AgentWorks OS Selected Logo Pack

Selected direction: **1A Line Gate**.

This pack is aligned to the current SGRIDWORKS redesign while keeping AgentWorks OS as a standalone customer-facing product.

## Design System

- Display wordmark: Fraunces, matching the redesign lockup language
- OS label: JetBrains Mono, small caps, matching system/data labels
- UI/body companion: Inter
- Mark style: 32x32 thin-line SVG, same scale as SGRIDWORKS mark assets
- Geometry: policy gateway + central agent path + approval nodes

## Usage

- Use `lockup-default-light.svg` in light website headers, docs, and README surfaces.
- Use `mark-default-light.svg` for compact app UI, favicons, avatars, and sidebars.
- Use `lockup-default-dark.svg` or `mark-default-dark.svg` on dark terminal/admin surfaces.
- Use mono variants for print, engraving, simple badges, and constrained partner surfaces.

## Notes

This mark should not be described publicly as derived from internal substrate projects. Customer-facing usage should position it around AgentWorks OS: policy gateway, compliance firewall, approval path, auditability, and controlled agent action.
