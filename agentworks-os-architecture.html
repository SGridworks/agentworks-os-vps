AgentWorks OSv0.1

Multi-agent compliance platform — TypeScript monorepo • Node.js daemon + Python scanner worker

Policy Engine

  • • Evaluates agent actions against AWCP rule-packs
  • • 3-tier retrieval: tier=brief|summary|full
  • • cognitiveBudget hook at evaluation time
  • • Dispositions: pass · warn · block · escalate
  • • missing_data_disposition per-pack config

Memory Package

  • • FileVaultStore: YAML frontmatter, .details/, .snapshots/
  • • 3-tier retrieval: brief (1-2 sent) · summary · full body
  • • Lazy detail: detail_body → .details/ dir, detail_key ref
  • • Snapshot + restore before consolidate/prune
  • • Importance 1–5: recency + body len + eventCount
  • • Session briefs rendered on session close
  • • pruneVault() greedy algorithm, dry-run supported

AgentOS-D Daemon

  • • REST + MCP server (Express)
  • • Drizzle ORM: SQLite dev, Postgres prod
  • • Adapter SDK for agent orchestration
  • • Transparent proxy: X-Forwarded-For / CF-IP
  • • Circuit breaker, cost meter (v1.1)
  • • Session + issue management with dispatch
  • • Approval queue for human-in-loop

Scanner Worker (Python)

  • • FastAPI async task worker
  • • Dispatched from agentos-d scanner route
  • • PDF processing via pdf/ package
  • • n8n-nodes for workflow automation

Resilience

  • • Tenant isolation enforced at FS level
